# Quemarueda

Juego de drag (cuarto de milla, 402 m) para móvil. Mejora piezas, ajusta el reglaje y gana a 10 rivales.

- Antes del verde: mantén **GAS** y deja la aguja en la zona verde.
- En carrera: toca **CAMBIO** cuando las luces se pongan azules. **NITRO** si lo llevas.
- Teclado: espacio = gas/cambio, N = nitro.

Todo va en un solo archivo: `index.html` (HTML + CSS + JS, sin librerías). La partida se guarda en el navegador.
